# Robot Avatar 測試紀錄

## 2026-11-04：Unity Editor 骨骼與 Animator

環境：Unity 2022.3.22f1、VRChat SDK 3.10.6 官方 Robot PC 範例；以 batch mode 重載保存的測試場景，使用實際產生的 Gesture Animator 驅動 Humanoid 骨骼。batch mode 強制測試用 Animator 保持更新，以避免畫面外裁切影響結果。SDK 要求的 Gesture 第一層遮罩加入後，已重跑此測試並通過。

| 參數 | 零值關節角度 | 正值 1 關節角度 | 結果 |
| --- | ---: | ---: | --- |
| 左／右抬手 | 90.0° | 158.7° | 通過；負值也能放下 |
| 左／右彎肘 | 177.1° | 89.7° | 通過 |
| 左彎膝 | 179.8° | 92.2° | 通過 |
| 右彎膝 | 169.3° | 81.3° | 通過 |

六個參數各自驅動預期骨頭，全部同時作用時，與各自作用的局部旋轉差異均為 0.0°。測試也檢查非目標骨頭的局部旋轉、Avatar Root 位置及旋轉不變；膝蓋的 Tracked → Moving → Tracked 狀態切換通過。

最初的逐片段取樣曾通過，但實際 Animator 測試發現同側彎肘圖層覆蓋抬手圖層，且零值肘／膝約彎曲 80°。已改成同側手臂共用混合樹，並調整 Robot 模型的中立肌肉值後重測通過。

## 2026-11-04：SDK 本機 Build & Test

首次建置因 Gesture 第一個 Animator 圖層沒有 Avatar Mask 而未通過 SDK 驗證。加入僅啟用雙臂及雙腿的遮罩後，SDK `BuildAndTest` 回報成功，並在本機 VRChat 測試 Avatar 資料夾產生 `Tutorial_Robot_Avatar_Dynamics_Demo_v1.vrca`（763,987 bytes）。這是本機測試建置，沒有上傳；遊戲內的後續結果另列於下。

## 2026-11-04：VRChat Desktop 首輪遊戲內測試

使用者已套用本機 Robot，開啟 OSC Debug 後 VRChat 監聽 UDP 9000。依序將六個參數設為 1 再歸零時，從 VRChat 的 UDP 9001 分別觀測到六個對應參數的 `0 → 1 → 0` 回傳；這證明參數變化有進入 VRChat，但不單獨證明骨骼動作。

使用者在世界中的全身鏡觀察，回報左抬手正確，上半身動作正常；左、右彎膝都沒有看到成功。第一次嘗試 WASD 時沒有看到角色移動；關閉選單、確認遊戲焦點後，使用者確認 WASD 能移動，且在左抬手與左彎肘同時作用期間仍可使用四個方向、左臂姿勢保持正常。重測左彎膝時，使用者回報角色靜止時腳部不動，只有使用 WASD 時看到走路造成的彎曲；不能將走路動畫計為姿勢參數成功。監聽 `VelocityMagnitude` 等 OSC 輸出沒有收到樣本，不能用它推斷有無移動。

為排查雙膝，另以 Unity PlayableGraph 將 Gesture 疊到 SDK 範例 locomotion controller；左右膝的局部旋轉各改變 88.0°。此近似測試不含 VRChat 的 IK。加入靜止時腳部 `Animation`、移動時腳部 `Tracking` 後，使用者在遊戲中確認左右膝靜止時都能正常彎曲並伸直；但保持彎膝參數時，角色雖能以 WASD 移動、左臂保持姿勢，雙腿卻維持彎曲而滑行。

接著將雙膝移至官方 locomotion 控制器副本的加算圖層，Gesture 遮罩改為僅雙臂；移動狀態使用零加算量。Unity 重新載入場景後，六關節與簡化 PlayableGraph 的走路釋放測試通過，SDK 本機 Build & Test 也已成功。

## 2026-11-04：修正版 VRChat Desktop 共存重測

使用者重新套用本機 Robot 後，診斷工具同時將左抬手、左彎肘及左右彎膝設為 1，維持 30 秒後歸零；四個參數都從 VRChat 的 UDP 9001 回傳 `0 → 1 → 0`。使用者確認 WASD 可正常移動、雙腿移動時正常交替走路，停下後恢復彎膝，左臂姿勢也保持正常。

這次是從 Windows 診斷工具直接送 OSC，證實本機遊戲內動作與鍵盤共存，**不是手機經 Wi-Fi、receiver 到 VRChat 的完整流程測試**。本機測試 Avatar 的遠端可見性也未驗證。

## 2026-11-04：待機姿勢修正

使用者指出原本零值是 T 字平舉，因此未追蹤時也維持平舉。現將左右抬手的 Avatar 預設及無追蹤待機值改為 -1（手臂放下），其他四個關節的待機值維持 0；手機 T 字校正後的零點與姿勢轉換不變。Unity 的待機骨骼測試量得左右上臂與軀幹夾角各約 3.5°，六關節及走路圖層測試通過；Windows 自動測試 9 項及 OSC 診斷工具 loopback 待機值檢查通過，SDK 本機 Build & Test 重新建置成功。使用者重新套用最新版後，已在 VRChat 確認雙臂自然放下。
